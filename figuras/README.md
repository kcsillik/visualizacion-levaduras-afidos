# Figuras

Esta carpeta reúne las visualizaciones elaboradas para el proyecto de análisis de respuestas de áfidos a tratamientos con levaduras.

Actualmente contiene una primera figura. Se incorporarán nuevas visualizaciones conforme avance la revisión de los análisis.

Todos los gráficos se elaboran a partir de datos simulados y tienen fines exclusivamente didácticos.
